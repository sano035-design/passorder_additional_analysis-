# Data 폴더 안내

본 `data/` 디렉토리는 데이터 분석 및 대시보드 구축의 기반이 되는 **원천 데이터 파일(Raw Data) 및 가공 데이터**를 보관하는 폴더입니다.

---

## 1. 보관 대상 파일
* 원천 로그 데이터: `*.csv`, `*.parquet`, `*.jsonl` 등
* 보조 메타데이터: 마스터 코드 테이블, 매장/상품 카테고리 매핑 테이블 등

## 2. 데이터 관리 원칙
1. **원천 데이터 불변성**: 분석 스크립트 실행 시 원천 파일 자체를 덮어쓰거나 변형하지 않습니다.
2. **파일명 명명 규칙**: `[프로젝트명]_[데이터종류]_[기간].csv` 형태로 명확하게 식별할 수 있도록 저장합니다.
3. **스키마 동기화**: 본 폴더에 들어간 데이터의 컬럼 구조와 타입은 반드시 [`docs/docs.md`](../docs/docs.md)의 6번 섹션(데이터 파일 및 상세 설명)에 정확히 기재해야 합니다.
