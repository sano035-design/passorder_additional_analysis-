# Templates 폴더 안내

본 `templates/` 디렉토리는 대시보드나 웹페이지를 제작할 때 **기본 지침서(`docs.md`)가 있더라도 프로젝트 상황에 따라 참고할 수 있는 레퍼런스 .html 웹페이지, 컴포넌트 템플릿 또는 레퍼런스 이미지/에셋**을 보관하는 폴더입니다.

---

## 1. 보관 대상 파일
1. **레퍼런스 HTML 웹페이지**:
   - 벤치마킹 대상 웹사이트/대시보드의 저장된 `.html` 파일
   - 특정 UI 인터랙션(탭 전환, 아코디언, 툴팁 등)의 독립 프로토타입 코드
2. **브랜드 및 디자인 에셋**:
   - 브랜드 공식 로고 이미지: `brand_logo.png`, `brand_logo.svg`
   - 브랜드 비주얼 가이드/톤앤매너 이미지: `tone_manner_reference.png`
   - 참고 레이아웃/인포그래픽 스크린샷

## 2. 활용 방법
* AI 에이전트에게 대시보드 시각화나 브랜딩을 요청할 때, *"templates/ 폴더의 brand_logo.png와 tone_manner_reference.png를 참고하여 대시보드 헤더와 컬러 테마를 맞춰줘"*와 같이 컨텍스트로 제공할 수 있습니다.
