# Docs 폴더 가이드 및 파일 보관 원칙

본 `docs/` 디렉토리는 프로젝트의 기획, 지침, 문서 및 **분류가 모호한 각종 파일**을 보관하는 공식 저장 공간입니다.

---

## 1. 주요 구성 파일
* [`docs.md`](docs.md): AI 에이전트가 데이터 분석, 가설 검증, 대시보드 구축을 수행할 때 참고하는 핵심 프로젝트 지침서입니다.
* [`readme.md`](readme.md): GitHub 리포지토리 메인에 업로드할 프로젝트 포트폴리오 및 성과 소개 문서입니다.

---

## 2. ⭐️ 분류가 어려운 파일 보관 원칙 (Important Rule)

> **원칙**: `data/`, `output/`, `templates/` 등 명확한 전용 폴더로 분류하기 애매하거나 성격이 복합적인 모든 파일은 **본 `docs/` 폴더에 보관**합니다.

### 보관 대상 예시:
1. **기획 및 비즈니스 자료**: PDF/Word 형식의 회사 분석 보고서, 비즈니스 모델(BM) 문서, 과제 제안서
2. **도메인 연구 문서**: 리서치 메모, 시장 조사 리포트, 논문 요약본
3. **회의록 및 요구사항 명세**: 이해관계자 회의록, 인터뷰 기록, 변경 이력 노트
4. **API 명세서 및 데이터 딕셔너리 추가본**: 비공식 스키마 정의서, 보조 메타데이터 문서
